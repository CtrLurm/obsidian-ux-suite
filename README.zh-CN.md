# Obsidian 体验优化套件

[![English](https://img.shields.io/badge/English-2f81f7?style=flat-square)](./README.md)
[![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d73a4a?style=flat-square)](./README.zh-CN.md)

一组仅支持 Obsidian 桌面版的插件，目标是减少鼠标操作中的摩擦，让日常文件操作更顺手、更安全。套件刻意保持小而专注：每个插件只做一件事，默认保留 Obsidian 的原生行为作为回退，不修改你的笔记内容。

## 插件一览

| 插件 | ID | 作用 | 主要用法 |
| --- | --- | --- | --- |
| **鼠标手势** | `mouse-gesture` | 像 Edge 一样按住右键画手势，执行前进后退、标签页、滚动和任意命令。 | 按住右键画方向，松开执行。 |
| **回收站** | `obsidian-recycle-bin` | Obsidian 内嵌回收站，保留原始路径，可多选恢复或彻底删除。 | 正常删除后，从功能区或命令面板打开回收站。 |
| **文件框选与浮窗** | `file-marquee-floating` | 在文件列表长按框选、批量移动/删除，并把文件列表或功能区拉成 PS 风格浮窗。 | 长按文件列表空白处框选；长按标题栏或功能区空白处拉出浮窗。 |

## 安装

### 方式 A：发布包（推荐）

1. 打开 [Releases](https://github.com/CtrLurm/obsidian-ux-suite/releases) 页面，下载需要插件的 zip。
2. 解压到：

   ```text
   <你的仓库>/.obsidian/plugins/<插件 ID>/
   ```

   目录中应包含 `main.js`、`manifest.json`、`styles.css`。
3. 在 Obsidian 打开 **设置 → 第三方插件**，刷新列表并启用插件。
4. 如果插件没有立即出现，重启 Obsidian。

### 方式 B：从仓库安装

克隆仓库后复制插件的运行时文件：

```bash
mkdir -p "<你的仓库>/.obsidian/plugins/mouse-gesture"
cp plugins/mouse-gesture/{main.js,manifest.json,styles.css} \
   "<你的仓库>/.obsidian/plugins/mouse-gesture/"
```

`obsidian-recycle-bin` 和 `file-marquee-floating` 同理。

### 注意

- 三个插件均仅支持桌面版（`isDesktopOnly: true`），移动端不会加载。
- 仓库不包含任何仓库数据；测试使用临时文件，结束后已清理。
- 插件按现状提供，不附带担保；重要仓库请先在副本中测试。

## 1. 鼠标手势

**功能**

按住鼠标右键画出方向，松开后执行动作；没有画手势的普通右键仍然打开 Obsidian 原生菜单。界面会绘制手势轨迹和动作提示。默认覆盖前进后退、滚动、顶部/底部、标签切换、关闭/恢复标签、新建标签和重新加载。

**用法**

1. 按住**鼠标右键**，移动至少约 8 px。
2. 画一段或多段直线；每段建议至少约 26 px，识别更稳定。
3. 松开。如果没有画出方向，会打开普通右键菜单。
4. 打开 **设置 → 鼠标手势**，可编辑映射、轨迹颜色、动作提示，或在 Canvas/Excalidraw 中禁用。

**默认手势**

| 手势 | 动作 |
| --- | --- |
| `←` | 后退 |
| `→` | 前进 |
| `↑` | 向上滚动 |
| `↓` | 向下滚动 |
| `↓↑` | 回到顶部 |
| `↑↓` | 回到底部 |
| `↓→` | 关闭标签页 |
| `←↑` | 恢复关闭的标签 |
| `→↑` | 新建标签页 |
| `↑←` | 左标签页 |
| `↑→` | 右标签页 |
| `→↓` | 重新加载 |

**自定义映射**

每行写法为 `手势 = 动作`；方向用 `U/D/L/R`（或 `↑↓←→`）。`#` 或 `//` 开头为注释。`none` 禁用某个手势；`cmd:<命令 ID>` 执行任意 Obsidian 命令。

```text
L = back
R = forward
DR = close-tab
RL = cmd:my-plugin:some-command
D = none
```

**设置：** 启用、轨迹颜色、动作提示、在 Canvas/Excalidraw 中禁用、可编辑映射表。

## 2. 回收站

**功能**

删除文件时先复制到插件自己的回收站，记录原始仓库路径，再删除源文件；不会直接丢进系统回收站。支持文件、文件夹和整棵目录树。可在侧边栏集中查看，单选/全选后恢复或彻底删除。

**用法**

1. 在 Obsidian 中正常删除文件或文件夹（文件列表、标签页菜单或删除确认框）。
2. 从左侧功能区垃圾桶图标打开回收站，或在命令面板执行 **回收站: 打开回收站**。
3. 勾选条目（或全选），选择 **恢复所选** 或 **彻底删除**。
4. 恢复通过 Vault API 在原路径重建文件/文件夹；如果原位置已有同名项，会跳过并报告冲突，不覆盖。

**设置：** 启用/停用拦截、删除后显示提示、显示回收站绝对路径、清空回收站。

**数据位置**

```text
<仓库>/.obsidian/plugins/obsidian-recycle-bin/bin/
├── index.json                 # originalPath、type、deletedAt、size
└── data/<条目 ID>/<名称>       # 复制的文件或文件夹树
```

**兼容性：** 可与 Obsidian 原生“删除文件”设置共存；停用插件后恢复原生删除行为。只拦截经过 `FileManager.trashFile` 的删除。

## 3. 文件框选与浮窗

**功能**

面向左侧文件列表的桌面交互层：

- **长按框选**：在文件列表空白处按住左键，拖出矩形框，选中所有相交的文件/文件夹。
- **批量操作**：把选中项移动到另一个文件夹，或走 Obsidian 正常删除流程（可接入上面的回收站插件）。
- **拉出浮窗**：长按文件列表标题栏，把真实文件列表拉进浮窗；长按功能区空白处，拉出 PS 风格功能区浮窗。
- **功能区浮窗行为**：浮窗存在时原功能区完全隐藏；把浮窗拖到左边缘（28 px 内）会停靠复原；八向手柄支持左键缩放；图标按 2–5 列自适应网格排列。
- **保留原生提示**：浮窗打开时，Obsidian 的悬停提示会显示在浮窗之上。

**用法**

1. **框选**：在文件列表空白处按住左键约 0.3 秒，拖动后松开；底部工具条显示 `已选 N 项 / 移动… / 删除 / 取消`。
2. 框选时按住 **Ctrl**（macOS 为 **Cmd**）可追加选择。
3. **移动**：点 **移动…**，搜索或选择目标文件夹；同名冲突会跳过，不覆盖。
4. **删除**：点 **删除** 并确认；使用 Obsidian 正常删除流程。
5. **文件列表浮窗**：长按文件列表标题栏空白处并拖动；真实文件列表叶进入浮窗，滚动、右键菜单和框选继续可用。点 **还原** 或 **×** 归位。
6. **功能区浮窗**：长按功能区空白处并拖动；原功能区隐藏，拖到左边缘可停靠复原。可从任意边/角缩放，图标自动重排。
7. 命令：**浮窗显示文件列表**、**浮窗显示功能区**、**清除文件框选**、**启用或停用文件框选**。

**设置：** 启用、长按时间（160–900 毫秒，默认 320）、显示选框工具条、启用浮窗、恢复默认。

**限制：** 仅桌面版；框选只作用于文件列表；移动冲突会跳过；特殊主题或 Obsidian 未来 DOM 变化可能需要适配选择器。

## 从源码构建

三个插件相互独立。例如：

```bash
cd plugins/file-marquee-floating
npm install
npm run build
npm test
npm run smoke
npm run package
```

`npm run release` 会依次执行 build + test + smoke + package。Windows PowerShell 若禁止 `npm.ps1`，请使用 `npm.cmd`。

## 已验证

Windows 桌面版 Obsidian **1.15.1**：

- 鼠标手势：原生右键菜单、新建/关闭标签手势、设置解析。
- 回收站：真实文件删除、文件夹删除、单选/全选恢复、彻底删除、设置页。
- 文件框选：框选、批量移动/删除、浮窗内框选、文件列表/功能区浮窗开关与停靠、缩放、克隆按钮映射、提示层级、功能区完全隐藏。

三个插件分别有 22、13、10 个自动测试，另有通过 Obsidian stub 加载构建产物的 smoke 测试。
