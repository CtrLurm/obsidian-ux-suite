# 鼠标手势

[![English](https://img.shields.io/badge/English-2f81f7?style=flat-square)](./README.md)
[![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d73a4a?style=flat-square)](./README.zh-CN.md)

Obsidian 桌面版的 Edge 风格右键手势。在界面上画出方向，松开右键，执行导航、标签页、滚动或任意命令。

## 功能

- 右键手势识别，绘制实时轨迹和动作提示。
- 普通右键仍然打开 Obsidian 原生菜单。
- 默认 12 条手势，覆盖导航、标签页、滚动和重新加载。
- 每条手势都可以重映射、用 `none` 禁用，或用 `cmd:<命令 ID>` 绑定任意命令。
- 可在 Canvas / Excalidraw 中暂停响应。
- 可设置轨迹颜色、动作提示和映射表。

## 默认手势

| 手势 | 动作 |
| --- | --- |
| `←` | 后退 |
| `→` | 前进 |
| `↑` | 向上滚动 |
| `↓` | 向下滚动 |
| `↓↑` | 回到顶部 |
| `↑↓` | 回到底部 |
| `↓→` | 关闭标签页 |
| `←↑` | 恢复关闭的标签 |
| `→↑` | 新建标签页 |
| `↑←` | 左标签页 |
| `↑→` | 右标签页 |
| `→↓` | 重新加载 |

## 用法

1. 按住**鼠标右键**，移动至少约 8 px。
2. 画一段或多段直线，每段建议至少约 26 px。
3. 松开后执行映射动作；没有画出方向时打开原生菜单。
4. 打开 **设置 → 鼠标手势**，可修改映射、颜色、动作提示，或按视图暂停。

## 自定义映射

每行一条：

```text
L = back
R = forward
DR = close-tab
RL = cmd:my-plugin:some-command
D = none
```

方向用 `U/D/L/R` 或 `↑↓←→`。`#` 或 `//` 开头为注释。`none` 禁用某个手势；`cmd:<命令 ID>` 执行任意已安装命令。

## 安装

见[套件安装说明](../../README.zh-CN.md#安装)。插件 ID 为 `mouse-gesture`。

## 说明

- 仅桌面版。
- 插件在 window 层监听，因此编辑器、侧边栏、标签栏和设置窗口都能响应手势。
- 输入框和文本区域保留正常的右键行为。
- 手势映射保存在插件数据中，重启后仍然有效。

属于 [Obsidian 体验优化套件](../../README.zh-CN.md)。
