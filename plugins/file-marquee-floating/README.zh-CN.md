# 文件框选与浮窗

[![English](https://img.shields.io/badge/English-2f81f7?style=flat-square)](./README.md)
[![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d73a4a?style=flat-square)](./README.zh-CN.md)

面向 Obsidian 左侧文件列表的桌面交互增强：拖出矩形框多选文件，一次移动或删除；需要更大空间时，把文件列表或功能区拉成浮窗。

## 功能

- 在文件列表空白处长按后拖出**矩形框选**。
- **批量移动**：带搜索的目标文件夹选择器。
- **批量删除**：走 Obsidian 正常删除流程，可与回收站插件联动。
- **Ctrl/Cmd 追加选择**。
- **文件列表浮窗**：移动真实文件列表叶，滚动、右键菜单和框选继续可用。
- **功能区浮窗**：PS 风格；原功能区完全隐藏，支持自适应网格、八向缩放和拖回左边缘停靠。
- **原生悬停提示**在浮窗之上显示，不会被遮挡。

## 用法

1. **框选**：在文件列表空白处按住左键约 0.3 秒，拖动后松开。
2. **移动**：点击 **移动…**，选择目标文件夹并确认；同名项会跳过。
3. **删除**：点击 **删除** 并确认。
4. **追加选择**：框选时按住 **Ctrl**（macOS 为 **Cmd**）。
5. **文件列表浮窗**：长按文件列表标题栏空白处，拖动并松开；点 **还原** 或 **×** 归位。
6. **功能区浮窗**：长按功能区空白处；拖到左边缘（28 px 内）可停靠复原，原功能区随之恢复。
7. **缩放**：拖动浮窗任意边或角；图标按 2–5 列自适应重排。

## 设置

- 启用或停用插件。
- 长按时间：160–900 毫秒，默认 320。
- 显示或隐藏选框工具条。
- 启用或停用浮窗。
- 恢复默认。

## 命令

- **浮窗显示文件列表**
- **浮窗显示功能区**
- **清除文件框选**
- **启用或停用文件框选**

## 限制

- 仅桌面版。
- 框选只作用于文件列表。
- 移动冲突会跳过，不覆盖。
- 特殊主题或 Obsidian 未来 DOM 变化可能需要调整选择器。
- 浮窗会移动真实 DOM；Obsidian 正在重排工作区时尽量不要关闭浮窗。
